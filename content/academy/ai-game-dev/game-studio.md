<div class="lesson-section">
  <span class="section-label">The Studio Mindset</span>
  <h2 class="section-title">One person. Studio-level output.</h2>
  <div class="section-text">
    <p>You've now built a game from scratch using AI. You understand mechanics, art, audio, levels, multiplayer, mobile, and publishing. The question isn't "can I make games?" anymore. It's "how many can I ship?"</p>
    <p>A solo AI game studio operates on velocity. The traditional studio spends 2 years on one game. You can ship a polished game every 2-4 weeks. That changes the math on everything.</p>
    <div class="callout">
      <strong>The portfolio model:</strong> Instead of betting everything on one game going viral, ship 10 games. Each one teaches you something. Each one has a chance to find an audience. One hit pays for the time spent on all ten.
    </div>
    <p>Consistency beats perfection. Ship, learn, ship again.</p>
  </div>
</div>

<div class="lesson-section">
  <span class="section-label">Workflow</span>
  <h2 class="section-title">Your repeatable game production pipeline.</h2>
  <div class="section-text">
    <p>Template everything. Every new game starts from the same base:</p>
    <p><strong>Day 1:</strong> Core mechanic prototype. One prompt to AI, one playable prototype. Test the fun factor with the simplest possible version.</p>
    <p><strong>Days 2-3:</strong> Art and audio pass. Generate sprites, backgrounds, and sound effects. Apply your consistent art style.</p>
    <p><strong>Days 4-5:</strong> Polish and levels. Add game feel, design 10+ levels or implement procedural generation. Add leaderboard.</p>
    <p><strong>Days 6-7:</strong> Mobile optimization, PWA setup, itch.io listing, launch marketing. Ship it.</p>
    <div class="tip-box">
      <strong>Build a starter template:</strong> Create a boilerplate HTML file with your game loop, responsive canvas, touch controls, audio manager, and PWA setup already built. Every new game starts from this base. Ask AI to build this template once.
    </div>
  </div>
</div>

<div class="lesson-section">
  <span class="section-label">Revenue</span>
  <h2 class="section-title">How indie games actually make money.</h2>
  <div class="section-text">
    <p>Let's talk money. Here are the models that work for solo developers:</p>
    <div class="callout">
      <strong>Ads (web games):</strong> Ad networks like Google AdSense pay per impression. A game with 10,000 monthly players can generate $50-200/month. Not life-changing, but it's passive income that compounds across multiple games.
    </div>
    <div class="callout">
      <strong>Premium (itch.io/app stores):</strong> Sell your game for $1-5. Low volume but higher revenue per player. Works best for games with clear value (story, depth, content).
    </div>
    <div class="callout">
      <strong>Sponsorship:</strong> Game portals (CrazyGames, Poki, Newgrounds) pay $500-5,000 for exclusive or non-exclusive licenses to host your game. This is real money for browser games.
    </div>
    <p>The sweet spot for most solo devs: free web version with ads + premium version on app stores + licensing deals with portals. Multiple revenue streams from one game.</p>
  </div>
</div>

<div class="lesson-section">
  <span class="section-label">Growth</span>
  <h2 class="section-title">The path from here.</h2>
  <div class="section-text">
    <p>You've completed this course. Here's what the next year looks like if you execute:</p>
    <p><strong>Month 1-3:</strong> Ship 3-5 small games. Build your portfolio. Learn what kinds of games you enjoy making and what audiences respond to.</p>
    <p><strong>Month 4-6:</strong> Double down on your best-performing genre. Build a slightly bigger game. Start a simple website showcasing your games.</p>
    <p><strong>Month 7-12:</strong> Build your first "real" game -- something with depth, content, and a $3-5 price tag. Launch on itch.io, web, and app stores. Apply to game portals for licensing deals.</p>
    <div class="tip-box">
      <strong>The long game:</strong> Most successful indie devs shipped 5-10 games before their breakout hit. Each game teaches you something no course can. The developers who win are the ones who keep shipping.
    </div>
    <p>You have the tools. You have the knowledge. The only thing left is to build. Go make something people can't stop playing.</p>
  </div>
</div>
